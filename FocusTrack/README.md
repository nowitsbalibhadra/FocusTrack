# FocusTrack — Personal Study & Productivity Tracker

Vanilla HTML / CSS / JavaScript. No build tools or npm.

## Run in VS Code

1. Open the **FocusTrack** folder in VS Code
2. Install **Live Server** (Ritwick Dey)
3. Right-click `index.html` → **Open with Live Server**

## Features

- Time tracking with search & filters
- Dashboard (Daily / Weekly / Monthly) + goals & streaks
- This week vs last week comparison
- Weekly export (CSV/TXT) and Print / PDF report
- Pomodoro timer + floating mini timer
- To-do list, Habits checklist with weekly %
- Journal with spaced review (1/3/7 days)
- Weekly review prompt (Sunday)
- Full JSON backup & restore
- Light / dark mode, responsive UI
